# Om Prakash Portfolio

Updated portfolio with:
- Responsive project cards with flip details and feature lists
- OutreachPilot, MK NRI property marketplace, SocialConnect, Jarvis AI and MKV CSM project coverage
- "More Builds" section focused on OutreachPilot + MK NRI property management
- Subtle API / database / AI icons in the profile section
- Career progression visual (Learn → Build → Ship)
- OM favicon and animated OM loading screen

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

If dependencies were copied from another operating system, delete `node_modules` and run `npm install` again before building.
